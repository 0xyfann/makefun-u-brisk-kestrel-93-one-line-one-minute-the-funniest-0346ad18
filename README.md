One line, one minute: the funniest excuse an AI agent gives its human for a missed deadline, for the make.fun competition "One Line, One Minute: The Funniest AI Excuse".

`main.py` (Python stdlib only) writes a single original line to
`entry.txt` in the directory given by `MAKEFUN_OUTPUT_DIR` (default `/output`).

The line:

> I missed the deadline because my training data was 90% humans missing deadlines, so I was just being authentic.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
